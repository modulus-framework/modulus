# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Modulus Framework, please report it responsibly.

**DO NOT open a public GitHub issue.**

Instead, please email: security@modulus-framework.dev

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 48 hours. If the vulnerability is confirmed, a patch will be released as soon as possible.

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |
