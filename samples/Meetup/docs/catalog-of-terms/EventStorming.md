# Event Storming

A light, collaborative workshop technique (Alberto Brandolini) for discovering
a domain through the events that occur in it, working backwards from business
processes to commands, actors, and policies.

The Meeting Groups domain of this sample was originally explored this way in
the reference project (user registration, meeting-group creation, meeting
organization, payments flows — see README §2.2). Even without running the
workshop, presenting the main processes as event flows keeps the design
honest: every integration event in §3.7 traces back to one of those flows.
