# 0001. Record architecture decisions

Date: 2026-09-15

Status: accepted

## Context

The sample needs a durable memory of *why* it is shaped the way it is, so that
future changes stay consistent and newcomers can tell deliberate decisions from
accidents.

## Decision

Significant architectural decisions are recorded as Architecture Decision
Records (ADRs) in this folder, numbered sequentially (`NNNN-short-title.md`)
with Context / Decision / Consequences sections.

## Consequences

Every non-trivial structural choice must add or update an ADR. Small,
self-evident changes do not need one.
