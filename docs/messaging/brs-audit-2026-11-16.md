# Modulus.Messaging: BRS audit, 2026-11-16

Every business, functional, non-functional and rule requirement in the
[BRS](../Cobytelabs.Messaging%20—%20Business%20Requirements%20Specification%20(BRS).md),
checked against the code and the evidence the tests and runs give. Status: **Met**, **Partial** (built with a stated
limit), **Not met**, **Decided** (not built by an owner decision), **Open** (waiting on the owner or hardware), or
**Not verified** (no evidence yet).

Evidence in brackets: unit test class, Docker integration run (PostgreSQL 17 and RabbitMQ 3.13 on Docker Desktop,
2026-11-16), or benchmark run. The integration runs were 33/35 (PostgreSQL) and 18/20 (RabbitMQ); the four failures are
the database and broker restart tests, which fail on Docker Desktop because a restarted container gets a new port. They pass on Podman (2026-11-16, all messaging integration suites run there).

## Business rules

| ID | Rule | Status | Evidence and limit |
|---|---|---|---|
| RULE-01 | Outbox sends only if the transaction commits | Met | [TransactionalOutboxTests], [InMemoryOutboxTests]. |
| RULE-02 | Ack only after the consumer's transaction commits | Met | RabbitMQ and EF Core and Npgsql transactions. The in-memory transport has no ack (a known limit). |
| RULE-03 | Never dropped unless explicitly discarded | Met | No discard option exists. |
| RULE-04 | Applied at most once per consumer in the window | Met | [InboxTests]. |
| RULE-05 | A message keeps its producer's tenant; a tenant-scoped consumer rejects no-tenant messages | Met | `RequireTenant` and `no-tenant` parking; [TenantTests]. |
| RULE-06 | Saga state, inbox row and outgoing messages commit in one transaction | Met | Consumer writes, the inbox row and outgoing messages commit together ([InboxTests], Npgsql RULE_06 tests). The Npgsql saga repository now joins the scope's unit of work (it previously wrote outside it); `RULE_06_saga_*` tests check rollback and commit. |
| RULE-07 | Each attempt runs in a new DI scope | Met | `_scopes.CreateAsyncScope()` per attempt. |
| RULE-08 | Expired messages never reach user code | Met | TTL check before the consumer; [PostgreSqlTransportTests] (FR-13 on PostgreSQL). |
| RULE-09 | Request/response not captured by the outbox | Met | Documented limit; replies go straight to the transport. |
| RULE-10 | Message identity is a URN | Met, with a limit | `[MessageUrn]` (2026-11-16, [MessageUrnTests]). A type without the attribute keeps a name-derived URN, which renaming changes; analyzer MOD0006 reports it in projects that opt in with `ModulusRequireMessageUrn` ([MessageUrnAnalyzerTests]). |
| RULE-11 | Breaking changes get a new URN; both versions published during migration | Partial | Mechanism built ([MessageUrnTests]). `MessageUrnContract` fails the build when a recorded URN disappears ([MessageUrnContractTests]). A new URN for a breaking change is still a convention, not checked by the tool. |
| RULE-12 | A module consumes only another module's public contracts | Not verified | A framework-level architecture rule (`Modulus.Testing.Architecture`); not checked for messaging contracts here. |
| RULE-13 | Headers are never proof of identity or authorization | Met | Tenant headers are checked against the tenant store (D8); the encrypted-type header only selects a registered type. |
| RULE-14 | The narrowest configuration scope wins | Met | [ConsumerOptions] inheritance. |

## Summary

- **Met:** the large majority of business, functional, rule and non-functional requirements, with the tests and runs above as evidence.
- **Partial, a gap against the BRS:** FR-19 query correlation (by id only), FR-13 priority on RabbitMQ (Decided), FR-09 CLI replay (Decided).
- **Not met on this machine:** NFR-03, NFR-04 and NFR-05 need target hardware; the PostgreSQL number here is 1,220 msg/s on Docker Desktop.
- **Decided not met:** NFR-13 Native AOT.
- **Open, waiting on the owner:** NFR-21 signing certificate; NFR-20 hosting and samples.
- **Not verified:** RULE-12 module rule for messaging contracts (not applicable to the bus itself).
- **Environment:** the four restart tests (NFR-02, FR-24) failed on Docker Desktop; on Podman (2026-11-16) all messaging integration suites pass: PostgreSQL transports 35/35, Npgsql outbox 7/7, PostgreSQL sagas 5/5, RabbitMQ 28/28, messaging integration 6/6.
